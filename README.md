# trabajo01grupotd2026
El repositorio incluye los documentos de enunciados y soluciones de los problemas de Teoría de la Decisión bajo Incertidumbre de los 3 miembros del grupo presentados conjuntamente.
El primer ejercicio de cada bloque (cada miembro del grupo) incluye una tabla de decisión resuelta para beneficios y costes por cada uno de los métodos estudiados, incluyendo cada problema un cuestionario que contiene 5 preguntas verdaderas o falsa.
El segundo ejercicio de cada bloque incluye un problema que hace referencia a una situación real resuelto por todos los métodos al mismo tiempo. Dicho ejercicio incluye de igual manera el cuestionario de 5 preguntas.
